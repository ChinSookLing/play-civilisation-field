          Replay code

          First line "k: A" with k the turn and A, B, C or P (D only when the packet lists it). Optional second line "COMMENT: …", kept as plain text up to 280 characters. A wrong number is rejected and nothing is recorded. Paste a replay code or a packet's resume code to restore that exact turn.
